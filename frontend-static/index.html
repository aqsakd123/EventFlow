07 / repeatable proof

Run the deployment rehearsal

Use the same sequence against the static server, then against the React build served from the same proxy.

01

Start the lab

Run the consistency compose file. Confirm Gateway at http://localhost:28181.

02

Open identity

Keep the default organizer headers. Use one workspace so event visibility and tenant checks are deterministic.

03

Create and publish

Create a draft, load it, publish it, then use the selected UUID for all following panels.

04

RSVP and check-in

Register twice with the same idempotency key. Confirm the second response is the same logical registration.

05

Upload privately

Run both single PUT and multipart. Finalize, then open a signed download URL.

06

Switch frontend

Repeat from the React production build. Watch the browser console and network panel for cross-origin or stale asset issues.

Safety noteThis console sends real writes to the configured local Gateway. Use a disposable workspace and never point the identity form at production credentials.
